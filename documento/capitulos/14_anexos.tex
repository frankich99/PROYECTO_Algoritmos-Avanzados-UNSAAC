\subsection*{Anexo A: Instalación y configuración}
\addcontentsline{toc}{subsection}{Anexo A: Instalación y configuración}
\label{anexo:instalacion}
El proyecto se ejecutó con Python 3.12.8 en Windows 11. Los comandos siguientes reproducen el entorno desde la raíz del repositorio:
\begin{lstlisting}[language=bash, caption={Clonación, entorno virtual e instalación}]
git clone https://github.com/frankich99/PROYECTO_Algoritmos-Avanzados-UNSAAC.git
cd PROYECTO_Algoritmos-Avanzados-UNSAAC
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r python/requirements.txt
\end{lstlisting}
Los requisitos principales son Python 3.10 o superior, \texttt{pytest}, \texttt{networkx}, \texttt{osmnx}, \texttt{streamlit}, \texttt{plotly}, \texttt{pandas}, \texttt{numpy} y \texttt{matplotlib}. La compilación del informe requiere una distribución LaTeX con \texttt{pdflatex} y \texttt{biber}. La red OSM y el clima se versionan como \textit{snapshots}; no es obligatorio descargarlos para ejecutar las pruebas.

\subsection*{Anexo B: Uso del prototipo}
\addcontentsline{toc}{subsection}{Anexo B: Uso del prototipo}
\label{anexo:uso}

\paragraph{Suite de pruebas.} Desde la raíz:
\begin{lstlisting}[language=bash, caption={Ejecución de las 246 pruebas}]
.\.venv\Scripts\python.exe -m pytest python/tests -q
\end{lstlisting}

\paragraph{Interfaz de comandos.} Desde \texttt{python/}:
\begin{lstlisting}[language=bash, caption={Comandos principales de la CLI}]
..\.venv\Scripts\python.exe main.py list
..\.venv\Scripts\python.exe main.py run --queue all --trace
..\.venv\Scripts\python.exe main.py compare
..\.venv\Scripts\python.exe main.py astar --input data/processed/cusco_osm_drive.json
\end{lstlisting}

\paragraph{Aplicación web.} Desde \texttt{python/}:
\begin{lstlisting}[language=bash, caption={Ejecución de la aplicación Streamlit}]
..\.venv\Scripts\python.exe -m streamlit run app.py
\end{lstlisting}
La aplicación abre cuatro vistas: Comparación, Ruta OSM, Traza manual y Procedencia. Si no hay red, usa los \textit{snapshots} locales y lo indica en pantalla.

\paragraph{Reproducción del benchmark y las figuras.} Desde la raíz:
\begin{lstlisting}[language=bash, caption={Regeneración de resultados, tablas y figuras}]
.\.venv\Scripts\python.exe python/scripts/reproduce_canonical.py
\end{lstlisting}
El script escribe \texttt{python/data/processed/benchmark\_results.json}, \texttt{applied\_results.json}, las tablas de \texttt{documento/tablas/} y las figuras de \texttt{documento/figuras/}. No sobrescribe la red OSM ni el clima si los \textit{snapshots} ya existen.

\paragraph{Compilación del informe.} Desde \texttt{documento/}:
\begin{lstlisting}[language=bash, caption={Compilación con pdflatex y biber}]
.\compilar.ps1
\end{lstlisting}
