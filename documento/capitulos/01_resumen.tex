\section*{Resumen}
\addcontentsline{toc}{section}{Resumen}

El presente proyecto de investigación aplicada aborda el problema de determinación de rutas mínimas para vehículos de respuesta a emergencias en la compleja red vial urbana del Centro Histórico de la ciudad del Cusco. Dicha trama urbana se caracteriza por una marcada anisotropía topográfica, pendientes pronunciadas superiores al 12\%, calzadas coloniales angostas y restricciones de sentido único. Para resolver el problema de caminos mínimos desde un origen único (\textit{Single-Source Shortest Path}, SSSP), se diseña e implementa una arquitectura modular desacoplada que evalúa el Algoritmo de Dijkstra y el Algoritmo de búsqueda heurística $A^*$ utilizando tres estructuras de colas de prioridad con clave disminuible (\texttt{Decrease-Key}): el Min-Heap Binario Indexado tradicional ($O((|V| + |E|) \log |V|)$), el $d$-ary Heap con $d=4$ ($O((d \cdot |V| + |E|) \log_d |V|)$) optimizado para la explotación de la jerarquía de memoria caché del procesador, y el Fibonacci Heap ($O(|E| + |V| \log |V|)$ amortizado) mediante listas circulares doblemente enlazadas y cortes en cascada.

Asimismo, se formula una función de costo generalizado que penaliza la impedancia por gradiente altitudinal andino mediante el factor cuadrático $\Phi(\theta) = 1 + \alpha \cdot \max(0, \theta)^2$ con $\alpha = 2.5$, garantizando la preservación estricta de la subestructura óptima. El sistema cuenta con una arquitectura de software en cuatro capas, serialización canónica en formato JSON, graficación topológica automatizada en Graphviz y una suite de 221 pruebas automatizadas bajo el patrón Arrange-Act-Assert (AAA), incorporando un oráculo diferencial basado en NetworkX y verificación del Certificado de Optimalidad de Bellman en tiempo lineal $O(|V| + |E|)$. Las evaluaciones experimentales de escalabilidad computacional sobre redes sintéticas de hasta $|V| = 5,000$ vértices y $|E| = 16,500$ aristas demuestran que las estructuras basadas en arreglos contiguos (4-ary Heap y Min-Heap binario) superan sistemáticamente en tiempo de pared (\textit{wall-clock time}) al Fibonacci Heap debido a la sobrecarga por alocación dinámica de memoria y fallos de caché L1/L2, mientras que el algoritmo $A^*$ logra podar entre un 60\% y 70\% del espacio de búsqueda sin degradar la optimalidad global. Finalmente, se documenta la trazabilidad completa del atributo del graduado AG\_C06 (\textit{Aprendizaje a lo largo de la vida}).

\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This applied research project addresses the single-source shortest path (SSSP) problem for emergency response vehicles operating within the complex urban road network of the Historic Center of Cusco, Peru. This urban layout features severe topographic anisotropy, steep slopes exceeding 12\%, narrow colonial streets, and strict one-way traffic restrictions. To solve this problem, a decoupled modular software architecture is designed and implemented, evaluating both Dijkstra's algorithm and the $A^*$ heuristic search algorithm using three priority queue data structures supporting key decreases (\texttt{Decrease-Key}): the traditional Indexed Binary Min-Heap ($O((|V| + |E|) \log |V|)$), the 4-ary Heap ($O((d \cdot |V| + |E|) \log_d |V|)$) engineered to leverage CPU cache hierarchy, and the Fibonacci Heap ($O(|E| + |V| \log |V|)$ amortized) utilizing doubly linked circular lists and cascading cuts.

Furthermore, a generalized cost function is developed that penalizes Andean altitude gradients via a quadratic impedance factor $\Phi(\theta) = 1 + \alpha \cdot \max(0, \theta)^2$ with $\alpha = 2.5$, ensuring the strict preservation of the optimal substructure invariant. The software framework features a four-layer architecture, canonical JSON serialization, automated topological rendering with Graphviz, and a test suite comprising 221 automated tests following the Arrange-Act-Assert (AAA) pattern, incorporating a differential oracle against NetworkX and verification of Bellman's Optimality Certificate in linear time $O(|V| + |E|)$. Computational scalability benchmarks on synthetic networks up to $|V| = 5,000$ vertices and $|E| = 16,500$ edges corroborate that contiguous array-based heaps (4-ary Heap and Indexed Binary Heap) systematically outperform the Fibonacci Heap in wall-clock time due to dynamic memory allocation overhead and L1/L2 cache misses. Concurrently, the $A^*$ algorithm prunes 60\% to 70\% of the search space while preserving guaranteed optimality. Finally, comprehensive traceability for the Graduate Attribute AG\_C06 (\textit{Lifelong Learning}) is reported.

\noindent\textbf{Keywords:} Dijkstra's algorithm, $A^*$ algorithm, priority queues, indexed min-heap, $d$-ary heap, Fibonacci heap, urban road networks, Cusco, topographic impedance, lifelong learning, AG\_C06 attribute.
